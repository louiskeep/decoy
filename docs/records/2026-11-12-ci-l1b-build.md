## Re-anchor findings

- The lane rules come from the engine's CI-E2a files on engine main `426e6d05`
  (`ci/required-jobs.toml`, `ci/unlaned.toml`, `tests/sentry/tooling/_ci_lanes.py`). The engine
  helper is not in the shared `ci_scan/` package and imports an engine-only marker parser for its
  M5 rule, so the CLI holds an adapted copy, recorded as a `[[mirror]]` in `ci/vendored.toml`.
  It reuses the vendored `ci_scan._shell_tokens` and adds no second shell parser.
- Every `ci/vendored.toml` entry has the same sha256 on engine main `426e6d05`, so every `commit`
  now points there, and `tests/sentry/layout/test_vendored_files.py` pins the same commit.
- The CLI registers no pytest markers, so `[[marker]]` and `[[dedicated_marker]]` start empty and
  rules M1 to M6 have nothing to check today. M5 (gates.sh against a hosted regression lane) is
  dropped: the CLI has no hosted gates.sh suite lane.
- The `pytest` merge job is a three-leg matrix with a templated name, which the engine's R2
  refuses. Owner (a): keep job keys only; the CLI R2 allows a `python` matrix equal to
  `SUPPORTED_MINORS` in `scripts/dev/lock_version.sh`. Item 12's "remove `pytest (py3.11)`"
  became "drop `pytest` from the merge list" and "add a 3.13 leg".
- T3 and T4 needed workflow edits: 8 of 9 jobs had no `timeout-minutes` and `ci.yml` had no
  concurrency block. Owner: adopt both. Timeouts come from recent hosted wall times with
  headroom (pytest legs up to 15 min, so 45; the rest under 1 min, so 10 or 15). No existing
  value moved (layers-gate keeps 15).
- T2 (no path filters): `regen-diagrams.yml` filters its push trigger on purpose. Owner: keep
  the rule with one named `[[path_filter]]` exception in `ci/unlaned.toml`.
- Item 14: `testpaths = ["tests"]`, but hosted pytest runs `tests/unit tests/sentry` (ignoring
  `test_import_layers.py`, which `layers-gate` runs through `gates.sh`) and then `tests/e2e`.
  Owner: the union of automatic lane paths must cover every test folder under testpaths, and
  every `--ignore` must name a file another automatic job runs (rule P1). The hosted run is not
  regrouped.

## Fix round 1 (Codex R1, GO-WITH-FIXES)

- P1 reads `--ignore-glob` and `--deselect` as exclusions, like `--ignore`. Each must name a path
  another automatic job runs; a glob is compared as text, so a wildcard fails closed. A script
  now clears only a `.py` file: `scripts/cert_smoke.py` names `tests/e2e` in its text, which let
  `--deselect=tests/e2e` pass before.
- `load` reads `*.yaml` workflows as well as `*.yml`.
- T2 reverse check: a `[[path_filter]]` entry whose workflow has no path filter left is a
  finding.
- The seeded tests assert through `findings()`, so removing a rule from it turns them red.
