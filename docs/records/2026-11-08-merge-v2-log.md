# V2-LOG from the 2026-11-08 merges

Status: record

Follow-ups the gates logged as V2 (not V1-blocking) for the merges recorded in
[RECENTLY-SHIPPED](../RECENTLY-SHIPPED.md) on 2026-11-08. Each is a known gap, not a defect in
what shipped.

## CLI #118 (verbose traceback frame headers)

- `FORCE_COLOR` is treated as a terminal, so the off-terminal panel width rule does not apply when
  it is set.
- Off a terminal, the traceback panel is padded out to the widest frame header.
- The test reaches Rich's private `_force_terminal` to simulate a terminal.

## Engine #405 (SCAN-ML M1)

- `registry_renumber.py --check` is not wired into the gates; it is run by hand.
- `docs/reasons.md` keeps a one-line list of manifests that the renumber check misreads (line 21).
- The scanner taints by column name only; value-level taint is M2.
- The wave-b literal sentry covers a narrower set of call shapes than the plan described.

## Engine #406 (value-free discovery and subset errors)

- The chunked-carry error keeps its conversion error as `__cause__` for diagnosis (M2), and the
  full-frame path still carries an implicit `__context__` (M3). Neither reaches a non-admin surface.
- Frame locals in a traceback can still hold values; admin-log only.
- No mutation run on the final head.

## Engine #407 (init wizard E3)

- `KeyedColumn` fields are typed `str | None`, but the walk reads raw config, so a non-string name
  passes through unchanged.

## Engine #408 (derived expression visibility)

- `transforms/derived.py` picks the reason word by exact exception type; #406 matched subclasses.
  Both are value-free; only the word differs for a subclass.
- `_apply_bounds` sits outside the try, so `float()` on a huge int raises an uncoded
  `OverflowError` (predates the PR).
- `profile/_readers.__all__` leaves out `build_declared_source`; the package exports it.
- `_field_names.py` calls itself the scan behind every duplicate-name refusal, but
  `_faker_deterministic_admission.py`, `_window_admission.py`, `profile/_types.py`,
  `_strategies/__init__.py` and `subset/_preflight.py` keep their own checks. Some check config
  names, not source schemas. Move the source-schema ones onto the helper or narrow the docstring.
- Derived error text names columns (structure, not values). An ambient caller exception can stay
  as `__context__` (exception chain only).
- `test_duplicate_field_names_matrix.py` is 843 lines and `tests/physical/test_unified_slice_admission.py`
  938 lines: split when next touched.
- No mutation run on `repeated_names` on the final head.
- `registry_renumber.py --check` flags any changed line that names a version between base and
  head, so the `registry_version` anchor line in `docs/reasons.md` (which also lists older
  manifests) always fails the check after a renumber. Skip anchor-only changes or move the anchor
  to its own line.
