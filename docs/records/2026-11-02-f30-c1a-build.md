  same class the C1a exporter closes with a prepared request, one adapter and `stream=True`.
  Not fixed here (outside this slice); needs its own slice.

## Note for C1b: fork and the closed resource

The closed resource does not survive a fork. The SDK registers a fork handler that merges the
process resource detectors into the provider's resource in the child. C1b must not end spans in
forked children, or must re-pin the resource after the fork.
